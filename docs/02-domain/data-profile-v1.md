## Surprises

- **The free IEX feed does not reach back to 2016.** Requested 2016-01-04..2025-12-31; the earliest bar in the whole set is 2018-04-25 (e.g. SPY starts 2018-11-01). 29,050 expected sessions are therefore `before_first_bar`. The 10-year window is not available on the free plan; the effective window is about 2018-2025.
- **1,085 sessions inside each symbol's range have no bar** (`provider_gap`): IEX only reports days with IEX trades, so thinly traded symbols miss days that the consolidated tape has.
- **One corrupt bar:** T on 2021-06-11 has low = 0.0 while the other prices are about 29; the loader quarantined it (`non_positive_price`).
- **Same-day dividends:** 7 actions were first rejected as duplicates because a symbol can have a regular plus a special dividend on one ex-date (e.g. XLF 2016-03-18). The loader now sums them.
- NEE's 2-for-1 split (Oct 2020) shows as -74.95%, i.e. it was a 4-for-1; GE's reverse split shows +676%. Both are explained by corporate-action rows.
- Total 72,315 bars (about 1,364 per symbol), far below the ~125,000 a 10-year window would give.

## Decisions this implies for the schema

- Keep `volume` as bigint (IEX volumes are small but consolidated would be larger); `trade_count` and `vwap` stay nullable.
- Prices need numeric(18,6) and must allow no zeros (CHECK catches the T bar).
- `corporate_action` key needs dividends merged per ex-date (done in the loader), or an extra key column later.
- Add the data window (effective start 2018-04-25) to the data dictionary; consider SIP feed or another source for longer history.
