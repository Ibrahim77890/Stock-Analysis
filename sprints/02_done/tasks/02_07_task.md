# Task 02_07: Data lineage endpoint with feed and universe caveats

**Sprint:** 02     **Depends on:** 02_06     **Size:** S
**Concepts to read first:** [02_07 Feeds, volume and lineage](../concepts/02_07_data-feeds-volume-and-lineage.md), [01_04 Provenance](../../01_done/concepts/01_04_data-provenance-and-licensing.md)

## Goal
For any symbol, `GET /lineage/{symbol}` explains where its bars came from and what caveats apply.

## Context
Blueprint 23.2 "Data lineage panel". Sprint 01 stored manifests, ingestion jobs and quality results but nothing joins them.

## What to do
1. Implement a `lineage(conn, symbol, cursor=None)` function returning: provider, feed, adjustment of stored rows (`raw`), `retrieved_at`, file name and sha256, loader job id and its reconciliation counts, first and last bar date, bar count, and quality-flag counts by rule (only flags on dates `<= cursor` when a cursor is given).
2. Read the manifest file from `data/raw/alpaca/bars_1d/` for the retrieval time and feed; if the file is missing, return `manifest: null` and a warning, not an error.
3. Add static fields `feed_caveat` (IEX volume is a subset of consolidated volume) and `universe_caveat` (today's survivors only).
4. Expose it as `GET /lineage/{symbol}` with a response model; add it to the OpenAPI file.
5. Write tests: AAPL lineage matches the manifest hash on disk; unknown symbol gives 404; with a cursor earlier than a known flag, that flag is not counted (leakage); a missing manifest gives a warning.
6. Add a negative test: tamper with a copy of the manifest hash; lineage reports a hash mismatch instead of the stored value (reuse `verify_file`).

## Where to do it
- Folder / file: `services/market-data/src/market_data/lineage.py`, `api.py`, tests in `services/market-data/tests/`.
- Technology: Python, psycopg, FastAPI.
- Database schema/ownership: reads `market.ingestion_job`, `market.bar_daily`, `market.data_quality_result`; no writes.

## Inputs
Manifests, ingestion jobs, quality results from Sprint 01.

## Deliverables
- `lineage.py`, endpoint, updated OpenAPI file, tests.

## Acceptance criteria / tests
- [ ] AAPL lineage returns the sha256 found in its manifest and the job's reconciliation numbers.
- [ ] Both caveat strings are present.
- [ ] Cursor-bounded quality counts never include flags after the cursor.
- [ ] Hash tampering is reported.
- [ ] Standing invariants: reconciliation visible; replay boundary respected.

## Benchmark
Not applicable.

## Out of scope
A UI panel, lineage for derived series.

## Notes for the implementer
A bar's `ingestion_job_id` is the last job that wrote the row; document that it can differ between bars of one symbol after a revision.
