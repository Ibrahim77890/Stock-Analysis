# Task 03_09: Documentation, end-to-end check and sprint wrap-up

**Sprint:** 03     **Depends on:** 03_01 to 03_08     **Size:** M
**Concepts to read first:** all Sprint 03 concepts (skim)

## Goal
The sprint can be reproduced by someone else from the docs, a worked example shows the whole honest-backtest story on real data, and the sprint is ready to close.

## Context
Every sprint has a documentation task and a wrap-up.

## What to do
1. Finish `docs/02-domain/backtest.md`: model summary, metric table, hash recipe, fill models, luck control, cost sweep, known limitations (no dividends in returns, IEX volume irrelevant to price rules, survivorship-biased universe, one asset, fractional shares, flat bps costs, risk-free 0).
2. Add a worked example for AAPL and SPY (default 20/50): result at zero cost, at 5 bps slippage, vs buy-and-hold, fill-model comparison, shuffle-test percentile. Numbers come from the actual run; copy them from the output, do not estimate.
3. Add glossary terms (fill model, slippage, basis point, drawdown, Sharpe ratio, buy-and-hold, bootstrap, config hash; minimum 8) to `docs/02-domain/glossary.md`.
4. Add a "Sprint 3" section to the service README reproduction guide (commands, expected outputs).
5. Reproduce on a fresh empty database: migrate, load, run the suite with `TEST_DATABASE_URL`, run one saved backtest and reproduce it.
6. Run the full suite twice (with and without `TEST_DATABASE_URL`) and record passed/skipped counts.
7. For every open item (cold benchmark, API latency, licence PDFs) copy status into the note.
8. Write the completion note for each task in `completed/` and move unfinished items to `pending/` with reasons. Last step: write the sprint completion note `completed/03_09.md`.
