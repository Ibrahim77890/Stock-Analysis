# Task 03_03: Performance metrics and the buy-and-hold benchmark

**Sprint:** 03     **Depends on:** 03_02     **Size:** M
**Concepts to read first:** [03_04](../concepts/03_04_performance-metrics.md)

## Goal
Pure metric functions summarise any equity curve and trade list, and every backtest result comes with a buy-and-hold benchmark computed through the same engine path.

## Context
A strategy number means little without its baseline. Conventions (252 days, ddof 1, risk-free 0) are fixed here and documented.

## What to do
1. Implement in a `metrics` module: `total_return`, `cagr`, `annualised_volatility`, `sharpe`, `max_drawdown`, `exposure`, `trade_stats` (count, win rate, average pnl, total costs), `turnover`, and `summarise(equity, trades)` returning a dict.
2. Return `None` (not an exception or infinity) when undefined: fewer than 3 equity points for volatility/Sharpe, zero variance, zero trades for win rate.
3. Implement `buy_and_hold(bars, spec)` that uses the same engine with a target of 1 from the first bar (entry at the first available fill under the spec's fill model, same costs, one entry fee).
4. Write hand-computed golden cases (the 100, 110, 99, 120 example from the concept note and at least one more).
5. Document conventions in `docs/02-domain/backtest.md` (created now, extended in 03_09).

## Where to do it
- Folder / file: `services/market-data/src/market_data/metrics.py`, `backtest.py` (benchmark), `tests/test_metrics.py`, `docs/02-domain/backtest.md`.
- Technology: Python, Polars, NumPy.

## Inputs
- Equity frames from 03_02; no new data.

## Deliverables
- `metrics.py`, benchmark function, tests, docs page with the metric table.

## Acceptance criteria / tests
- [ ] Equity 100, 110, 99, 120: total return 0.20, max drawdown -0.10 (exact).
- [ ] Constant daily return 0.001 over 252 days: CAGR equals 1.001^252 - 1 within 1e-9; volatility 0 and Sharpe `None` (no division error).
- [ ] Random-input property test (seeded): max drawdown is always in [-1, 0]; total return equals last/first - 1.
- [ ] Sharpe equals `mean/std(ddof=1)*sqrt(252)` computed independently with NumPy on a 500-point random curve (within 1e-12).
- [ ] Negative tests: empty equity raises `ValueError`; negative equity raises `ValueError`.
- [ ] Real data: for AAPL from 2020-07-27 (first stored bar) to 2023 the benchmark total return is within 1% (relative) of `adjusted_close_last/adjusted_close_first - 1` less the entry cost effect at zero cost (document the exact comparison in the test).
- [ ] Standing invariant: reconciliation (strategy accounting identity still holds).

## Out of scope
- Risk-free rate from FRED, Sortino, alpha/beta, deflated Sharpe (deferred).
