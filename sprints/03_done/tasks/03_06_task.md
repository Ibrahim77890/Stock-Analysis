# Task 03_06: Cost sensitivity sweep

**Sprint:** 03     **Depends on:** 03_03     **Size:** S
**Concepts to read first:** [03_03](../concepts/03_03_transaction-costs-and-sensitivity.md), [03_04](../concepts/03_04_performance-metrics.md)

## Goal
A function reruns one strategy across a grid of costs and reports where it stops beating zero return and the buy-and-hold baseline.

## Context
Blueprint 23.2 "Cost sensitivity sweep" and 26.2 item 3.

## What to do
1. Implement `cost_sweep(bars, spec, grid_bps)` where each grid value sets slippage (and, optionally, commission) in bps; default grid `[0, 1, 2, 5, 10, 20, 50]`.
2. For each value return total return, Sharpe, trade count, total costs, and the benchmark's return at that cost.
3. Implement `break_even(rows, key)`: linear interpolation of the cost where strategy total return crosses 0 (and crosses buy-and-hold); `None` if never crossed within the grid.
4. Validate the grid (non-empty, no negatives, sorted unique).
5. Run on AAPL, SPY and a high-turnover setting (fast=2, slow=3) over each symbol's stored window to 2025-12-31 and record the tables in `docs/02-domain/backtest.md`.

## Where to do it
- Folder / file: `services/market-data/src/market_data/backtest.py`, `tests/test_cost_sweep.py`, `docs/02-domain/backtest.md`.
- Technology: Python, Polars.

## Inputs
- 03_02/03_03 outputs; real AAPL and SPY bars.

## Deliverables
- `cost_sweep`, `break_even`, tests, docs table.

## Acceptance criteria / tests
- [ ] Zero-cost row equals the plain `run_backtest` result exactly.
- [ ] Total return is non-increasing as cost rises (checked on three real series; if a series violates it, explain why in the note rather than weakening the test).
- [ ] `break_even` on a hand-made table returns the hand-computed interpolation.
- [ ] Negative tests: empty grid, negative value, unsorted or duplicate grid raise `ValueError`.
- [ ] Informational: the number of trades of the high-turnover setting is reported next to its break-even.

## Out of scope
- Size-dependent market impact, spreads from quote data.

## Notes for the implementer
Do not interpret a break-even as a prediction; it is a sensitivity of one historical path.
