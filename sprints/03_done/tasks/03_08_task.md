# Task 03_08: Expose every backtest function in Swagger

**Sprint:** 03     **Depends on:** 03_04, 03_05, 03_06, 03_07     **Size:** M
**Concepts to read first:** [03_05](../concepts/03_05_luck-controls-shuffle-and-bootstrap.md), [03_06](../concepts/03_06_reproducibility-hashing.md)

## Goal
Every function built in this sprint can be tried by hand in the Swagger UI, each in its own endpoint under a "Backtest" section, with examples that work without the database where possible.

## Context
The owner wants a separate interface per function for manual testing (continuing ADR 0007).

## What to do
1. Add router tag `Backtest` to `api.py` with these endpoints (names may follow the existing style):
   - `POST /backtests/simulate`: your own bars plus a spec, no database (prefilled example).
   - `POST /backtests/metrics`: your own equity values, returns the metric dict (no database).
   - `POST /backtests/run`: symbol/dates/spec from the database; `persist` flag (default false).
   - `POST /backtests/fill-model-comparison`
   - `POST /backtests/cost-sweep`
   - `POST /backtests/shuffle-test`
   - `GET /backtests`, `GET /backtests/{run_id}`, `GET /backtests/{run_id}/trades`, `GET /backtests/{run_id}/equity`
   - `POST /backtests/{run_id}/reproduce`
   - `POST /backtests/causality-check`
2. Use Pydantic request models with constraints (1 <= fast < slow, costs >= 0, n_paths <= 1000, grid length <= 20) and prefilled examples.
3. Map errors: unknown symbol 404; invalid spec 422; unsorted bars 400.
4. Refresh `docs/02-domain/openapi-market-data.json` with `uv run market-data export-openapi`; extend the contract test.
5. Update the README Swagger table.

## Where to do it
- Folder / file: `services/market-data/src/market_data/api.py`, `tests/test_api_backtest.py`, README, `docs/02-domain/openapi-market-data.json`.
- Technology: FastAPI, Pydantic (existing).
- Database schema/ownership: `persist=true` and reproduce write `research.*` only; document that in each endpoint description.

## Inputs
- 03_02 to 03_07 functions.

## Deliverables
- Endpoints, updated OpenAPI contract, tests, README section.

## Acceptance criteria / tests
- [ ] Every function from 03_02 to 03_07 is reachable by exactly one endpoint (a test lists them).
- [ ] `/backtests/simulate` with the golden case from 03_02 returns the hand-computed final equity.
- [ ] `/backtests/run` for AAPL twice with `persist=true` returns the same `run_id` and the database has one row.
- [ ] `/backtests/{id}/reproduce` returns `reproduced`.
- [ ] Negative tests: `fast >= slow` 422; unknown symbol 404; `n_paths` 5000 422; SQL-injection symbol 404 with `research` and `market` row counts unchanged.
- [ ] The OpenAPI contract test passes; renaming a field is detected (negative test as in Sprint 02).
- [ ] Standing invariant: replay boundary (endpoint with `end` earlier than the data end never returns later dates; fuzz 50 dates).

## Out of scope
- Authentication, background jobs, saving shuffle and sweep results.

## Notes for the implementer
Start the server with `uv run market-data serve` (loopback only) and click through each endpoint once; record that you did in the completion note.
