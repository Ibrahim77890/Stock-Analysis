# Task 06_02: Blind episodes: seeded, mixed real and synthetic, with no side channels

**Sprint:** 06     **Depends on:** none     **Size:** L
**Concepts to read first:** [06_01](../concepts/06_01_hindsight-bias-and-what-blind-must-hide.md), [06_05](../concepts/06_05_precommitment-append-only-records-and-resolving-outcomes.md)

## Goal
The service can open a **blind episode**: a seeded random window of real Tiingo bars or a seeded random walk, served only up to a server-side cursor with identity, dates, price level and absolute volume hidden. Episodes survive a restart.

## Context
Blueprint 23.2 (blind replay) and 23.3 item 7. The Sprint 02 replay session is in memory and echoes `symbol` and `start` at creation; `blind_view` rebases prices but leaves volume in absolute terms. This task builds the blind path properly and leaves the old replay endpoints unchanged.

## What to do
1. Migration `0010` (create `research.episode`): `episode_id text PK` (8 hex characters, random), `seed bigint`, `kind text CHECK (kind IN ('real','synthetic'))` (the actual kind), `kind_requested text CHECK (... 'real','synthetic','mixed')`, `symbol text NULL` (real only), `source text NULL`, `start_date date NULL`, `synthetic_vol real NULL`, `n_bars int CHECK (n_bars BETWEEN 60 AND 500)`, `initial_visible int CHECK (initial_visible >= 20 AND initial_visible < n_bars)`, `cursor_pos int CHECK (cursor_pos BETWEEN initial_visible AND n_bars)`, `volume_scale double precision`, `status text CHECK (status IN ('open','revealed'))`, `created_at`, `revealed_at`. Up, down, up.
2. Add to `synthetic.py` a pure `episode_series(seed, n_bars, annual_vol)`: zero-drift geometric random walk with valid OHLC and lognormal volume (reuse the logic of `generate_block`), deterministic for the seed.
3. Create module `src/market_data/episode.py` (the **only** module that queries `research.episode`; add the structural test) with:
   - `create_episode(conn, kind="mixed", n_bars=250, initial_visible=60, seed=None, source="tiingo")`: if `seed` is None draw one from `secrets`; with `mixed` the actual kind is chosen by the seeded RNG with probability 1/2; for real episodes pick uniformly among symbols that have at least `n_bars` contiguous stored sessions and a uniformly random start position so that the whole window fits (use `read.session_dates`); store everything needed to rebuild the same episode; compute `volume_scale = mean(volume of the first initial_visible bars)` once.
   - `episode_bars(conn, episode_id)`: bars for positions 1..`cursor_pos` only. Real: `read.get_bars(... source, max_date=date at cursor_pos, adjustment="split")` (adjusted as of the cursor date). Synthetic: regenerate from the seed and slice to `cursor_pos`. Return the **blind** frame: `day` (1..cursor_pos), open/high/low/close rebased so the first visible close is exactly 100 (scale fixed from the first bar, which is stable as the cursor moves), `rel_volume = volume / volume_scale`; no dates, no symbol, no factor columns.
   - `advance_episode(conn, episode_id, n=1)` (1 <= n <= 20; clamps at `n_bars`; refuses a revealed episode).
   - `get_episode_public(conn, episode_id)`: `episode_id`, `n_bars`, `initial_visible`, `cursor_pos` (as `day`), `status`, `kind_requested`, and nothing identifying. For `kind_requested = "mixed"` the actual kind stays hidden; for an explicit request it is shown (the learner asked for it).
4. Endpoints (new router in `api_learning.py`, tag **Learning**, included from `api.py`): `POST /episodes` (body `kind`, `n_bars`, `initial_visible`, `seed` optional), `GET /episodes/{id}` (public state), `GET /episodes/{id}/bars` (blind bars to the cursor), `POST /episodes/{id}/advance`. Unknown id 404; invalid sizes 422.
5. Measure the share of up days (close greater than previous close) over all real Tiingo bars and over a synthetic sample of 10,000 bars; record both in the completion note (they feed the base-rate discussion in 06_04).

## Acceptance criteria / tests
- [ ] Migration up/down/up leaves the same table list; `alembic heads` shows `0010`.
- [ ] Determinism: the same seed and kind produce identical blind bars (hash equal); a different seed produces a different episode.
- [ ] **Boundary fuzz:** for 50 random episodes and random cursors, `episode_bars` returns exactly `cursor_pos` rows, the first close is exactly 100.0, and recomputing from data truncated at the cursor date gives the same rows (causality). Advancing never exceeds `n_bars`; `n` outside 1..20 is rejected.
- [ ] **Identity-leak scan (negative test):** serialise the JSON of `POST /episodes`, `GET /episodes/{id}`, `GET .../bars` and `.../advance` for 50 seeded real episodes; none contains the symbol string (case-insensitive), the company name, any year token 2005 to 2025 as a whole word in a key or string value (numbers are not scanned for years: 100.2013 is a price), any ISO date string, an absolute close equal to a raw stored close, or an absolute volume present in `market.bar_daily` for that window. Volume is always `rel_volume` (mean of the first `initial_visible` bars equals 1.0).
- [ ] The rebasing scale does not change when the cursor advances (the first 60 rows are identical before and after an advance).
- [ ] A revealed episode refuses `advance` (409); a missing episode returns 404.
- [ ] `mixed` episodes: over 200 seeds both kinds occur in roughly equal numbers (between 40% and 60% each), and the public state of a `mixed` episode never contains `kind`.
- [ ] Structural test: no module except `episode.py` mentions `research.episode` in SQL.
- [ ] Standing invariants: replay boundary, causality, reproducibility.

## Benchmark (informational)
Record p50 and p95 of 200 `GET /episodes/{id}/bars` calls (250-bar real episode, local machine) in the completion note; do not state a target.

## Notes for the implementer
Famous crashes cannot be hidden by presentation; that is why synthetic episodes are mixed in and why the kind is hidden. Say so in the module docstring. Real episodes use Tiingo (long history); keep the source a parameter so a redistributable source can replace it later.
