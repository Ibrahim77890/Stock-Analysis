# Task 03_02: Backtest engine v1 (SMA crossover, next-open fills, costs)

**Sprint:** 03     **Depends on:** 03_01     **Size:** L
**Concepts to read first:** [03_01](../concepts/03_01_backtest-mechanics-and-fill-timing.md), [03_02](../concepts/03_02_moving-average-crossover.md), [03_03](../concepts/03_03_transaction-costs-and-sensitivity.md)

## Goal
A pure function `run_backtest(bars, spec)` turns a date-sorted bar frame and a spec into an equity curve and a trade list, following ADR 0009 exactly.

## Context
Blueprint 26.4 item 6. The engine takes bars as an argument (no database inside), so every test can use hand-made data and the same function serves the API and the shuffle test.

## What to do
1. Create `BacktestSpec` (typed, validated): symbol, start, end, `fast`, `slow` (1 <= fast < slow), `fill_model` (`next_open` | `same_close`), `commission_bps` >= 0, `slippage_bps` >= 0, `initial_cash` > 0.
2. Add `sma_crossover(df, fast, slow)` returning a 0/1 target per close using `indicators.sma` (null averages give 0).
3. Implement `run_backtest(bars, spec) -> BacktestResult` (`equity` frame: trade_date, equity, position; `trades` frame; `realisable` flag false for `same_close`).
4. Fills: `next_open` fills at the next bar's open, buy at `open*(1+slip)`, sell at `open*(1-slip)`, commission `bps * notional` on each fill, all-in/all-out with fractional shares. A position still open on the last bar is recorded as a trade with `closed = false`, valued at the last close with no exit cost, so the accounting identity holds (stated in the ADR).
5. Equity at each close = cash + shares * close.
6. Reject unsorted bars, duplicate dates, fewer than 2 bars, non-positive prices (clear `ValueError`).
7. Hand-compute and test golden cases (see Acceptance criteria).
8. Add a repository-level helper `backtest_from_db(conn, spec)` that loads `get_bars(..., adjustment="split")` for `[start, end]` and calls the engine.

## Deliverables

- `tests/test_backtest.py`.

## Acceptance criteria / tests
- [ ] Golden case A (zero costs): closes/opens given in the test, fast=2, slow=3; expected trades, fill prices and final equity are hand-computed in comments and match to 1e-9.
- [ ] Golden case B: same data with commission 10 bps and slippage 5 bps; final equity matches the hand-computed value; `initial_cash + sum(pnl) == final equity` (accounting identity from ADR 0009).
- [ ] No signal ever (flat prices): zero trades, equity constant at initial cash.
- [ ] `fill_model="same_close"` result has `realisable == False`.
- [ ] Negative tests: unsorted bars, duplicate dates, `fast >= slow`, negative cost, price <= 0 each raise `ValueError`.
- [ ] Real data: `backtest_from_db` on AAPL from its first stored bar (2020-07-27 in the loaded data; the plan assumed 2019) to 2023-12-31, spanning the 2020-08-31 split runs, equity never shows a one-day change below -30% caused by the split (adjusted input), and the accounting identity holds.
- [ ] Standing invariants: causality (tested in 03_04), reconciliation (accounting identity), determinism (two runs equal).

## Benchmark (when relevant)
- Informational: time of one 4-year AAPL run and of 100 runs on the same frame; record machine and numbers in the sprint completion note. Do not state them as goals.

## Out of scope

## Notes for the implementer
Use `shift(-1)` on the open column to get the next bar's open, and make the last row's fill null on purpose. Write the golden case on paper before coding.
