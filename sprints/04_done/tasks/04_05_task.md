# Task 04_05: Probabilistic and deflated Sharpe, and the overfitting meter

**Sprint:** 04     **Depends on:** 04_02     **Size:** M
**Concepts to read first:** [04_04](../concepts/04_04_sharpe-uncertainty-psr-and-dsr.md), [04_01](../concepts/04_01_overfitting-and-multiple-testing.md)

## Goal
Given a return series and the number of trials behind it, the system reports the probability that the true Sharpe exceeds zero (PSR) and exceeds the best-of-N luck level (DSR), and summarises a study in one "overfitting meter" record.

## Context
Blueprint 23.2 "Overfitting meter". Formulas are in the concept note and in Bailey and Lopez de Prado; implement them with the standard library plus NumPy.

## What to do
1. Implement `sharpe_moments(returns)` returning per-period Sharpe, `T`, skewness and (non-excess) kurtosis using sample moments; document the estimator.
2. Implement `probabilistic_sharpe(returns, benchmark_sr=0.0)` using `statistics.NormalDist`; return `None` with a reason when `T < 30` or the denominator is not positive.
3. Implement `expected_max_sharpe(n_trials, variance)` (0 for `n_trials == 1`) and `deflated_sharpe(returns, trial_sharpes)` where the variance comes from the trial Sharpe estimates.
4. Implement `overfitting_meter(conn, study_id)`: reads the study's train trials, returns N, the best train Sharpe (per period and annualised), SR0, and the DSR of the best trial's return series (recompute that series with `run_backtest` from the stored parameters).
5. Document formulas, estimators and the effective-N caveat in `docs/02-domain/validation.md`.

## Acceptance criteria / tests
- [ ] Golden: annualised Sharpe 1.0 over `T = 1000` normal-like daily returns gives `PSR(0)` within 0.002 of the independently computed value (about 0.977; compute the reference by hand in the test, not with the function under test).
- [ ] Golden: `T = 250` with the same Sharpe gives about 0.84 (same tolerance).
- [ ] Property tests: PSR rises with `T` at fixed Sharpe; DSR falls as the number of trials rises at fixed data; PSR at a higher benchmark is lower.
- [ ] `expected_max_sharpe(1, v) == 0`; `expected_max_sharpe(100, 1.0)` matches the formula evaluated independently.
- [ ] Monte Carlo (seeded, thresholds written before running): over 200 studies of 50 random-walk strategies each, the share whose best strategy has DSR > 0.95 is at most 10%, while the share with PSR(0) > 0.95 is clearly larger (the point of the deflation).
- [ ] Negative tests: `T < 30` returns `None` with a reason; constant returns (zero variance) return `None`; `n_trials < 1` raises `ValueError`.
- [ ] Standing invariant: reproducibility (seeded Monte Carlo identical across runs).

## Out of scope
- Effective-N estimation from trial correlation, minimum track record length, White's reality check.

## Notes for the implementer
The formulas need per-period Sharpe and plain kurtosis; most bugs here are an annualised input or an excess-kurtosis input.
