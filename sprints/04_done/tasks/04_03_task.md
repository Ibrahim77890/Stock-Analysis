# Task 04_03: Train/test split with embargo and a one-use holdout

**Sprint:** 04     **Depends on:** 04_02     **Size:** M
**Concepts to read first:** [04_02](../concepts/04_02_in-sample-out-of-sample-embargo-and-holdout.md)

## Goal
The system selects parameters on the training bars only, evaluates them once on later test bars (with warm-up and embargo), reports the in-sample to out-of-sample decay, and refuses to use the holdout a second time.

## Context
Blueprint 26.4 item 7. This task turns the search of 04_02 into an honest estimate.

## What to do
1. Implement `split_bars(bars, train_bars, embargo, test_bars=None, holdout_bars=0)` returning index ranges for train, test and holdout over the date-sorted frame; reject ranges that do not fit.
2. Implement `evaluate_split(bars, base_spec, grid, train_bars, embargo=5, test_bars=None, metric="sharpe")`: run `grid_search` on the train bars only, take the best pair, run it on the test bars preceded by `slow` warm-up bars (equity counted from the first test bar, starting flat), return IS metrics, OOS metrics, decay, OOS trade count and trial count.
3. Record train trials (phase `train`) and the single test evaluation (phase `test`) in the study.
4. Implement `final_holdout_evaluation(conn, study_id, bars, spec, ...)`: runs the chosen pair on the holdout once, records phase `holdout` and sets `holdout_used_at`; a second call raises `HoldoutAlreadyUsedError`.
5. Document the exact splitting and warm-up rule in `docs/02-domain/validation.md`.

## Where to do it
- Folder / file: `services/market-data/src/market_data/validation.py`, tests in `services/market-data/tests/test_validation_split.py`, `docs/02-domain/validation.md`.
- Technology: Python, Polars, psycopg 3.
- Database schema/ownership: `research.study`, `research.trial` (write).

## Inputs
- 04_02 functions; real SPY and AAPL bars; seeded synthetic bars.

## Deliverables
- `split_bars`, `evaluate_split`, `final_holdout_evaluation`, `HoldoutAlreadyUsedError`, tests, docs section.

## Acceptance criteria / tests
- [ ] Leakage test: change every test-block and holdout bar to random values; the selected pair and the train table are byte-identical (the central negative test).
- [ ] Split ranges: train ends at index `a`, test starts at `a + embargo + 1`; ranges never overlap (property test over 100 random sizes).
- [ ] Hand-computed case on a small frame: expected train best pair, OOS equity and decay.
- [ ] A second `final_holdout_evaluation` for the same study raises `HoldoutAlreadyUsedError`, adds no trial and keeps the first `holdout_used_at`.
- [ ] On pure random-walk synthetic data (seeded, 20 seeds, thresholds written before running: median decay > 0 in at least 14 of 20 seeds) the selected rule shows positive decay on average, which is the expected selection effect.
- [ ] Real data: SPY with train 1,000 bars, embargo 5, rest as test; IS Sharpe, OOS Sharpe, decay and OOS trades recorded in the completion note, whatever the direction.
- [ ] Standing invariants: causality (selection uses only train bars), replay boundary (no function reads bars past the requested end).

## Out of scope
- Anchored windows, purged k-fold, multiple holdouts.

## Notes for the implementer
A short OOS block with few trades is noisy: report the trade count next to every OOS number.
