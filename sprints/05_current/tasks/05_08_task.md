# Task 05_08: Expose the new functions in Swagger and add `source` / `price_basis` / `risk_free` options

**Sprint:** 05     **Depends on:** 05_03, 05_04, 05_05, 05_06, 05_07     **Size:** M
**Concepts to read first:** [05_04](../concepts/05_04_rate-limited-apis-and-resumable-downloads.md), [05_05](../concepts/05_05_risk-free-rate-and-macro-series-as-of.md)

## Goal
Every function from this sprint can be tried by hand in Swagger, and the backtest and validation endpoints accept the new options with safe defaults.

## Context
Continues ADR 0007 and the Sprint 03/04 pattern.

## What to do
1. Add a router (suggest `api_sources.py`, tag `Sources`) with: `GET /sources` (per source: symbols, bars, first and last date, action counts), `POST /ingestion/tiingo/download` (`max_requests` default 45, key from `.env`), `POST /ingestion/tiingo/load`, `POST /sources/reconcile` (symbols optional, writes a report file), `POST /ingestion/fred/download`, `POST /ingestion/fred/load`, `GET /macro/{series_id}` (range) and `GET /macro/{series_id}/asof` (`date`, `strict`), `GET /sources/adjustment-check/{symbol}`.
2. Add optional `source` (default `alpaca`), `price_basis` (default `split`) and `risk_free` (default false) fields to the Backtest and Validation request models; defaults must leave existing responses unchanged.
3. Errors: missing key 400 with the variable name only; quota reached 429; unknown symbol 404; `macro_asof` before first observation 404.
4. Refresh `docs/02-domain/openapi-market-data.json`; extend the tag and contract tests; update the README Swagger table and state which endpoints write or call vendors.
5. Show the FRED attribution notice in the description of the macro endpoints.

## Where to do it
- Folder / file: `services/market-data/src/market_data/api_sources.py`, `api.py`, `api_backtest.py`, `api_validation.py`, `tests/test_api_sources.py`, README.
- Technology: FastAPI, Pydantic (existing).
- Database schema/ownership: ingestion endpoints write `market.*` as the CLI does; nothing else.

## Inputs
- 05_02 to 05_07 functions.

## Deliverables
- Endpoints, refreshed OpenAPI, tests, README.

## Acceptance criteria / tests
- [ ] A test lists every Sprint 05 function with its endpoint.
- [ ] With the HTTP layer mocked, download endpoints honour `max_requests` and return 429 on quota; responses, logs and error bodies never contain the fake key (negative test).
- [ ] Existing Sprint 03 and 04 endpoint tests pass unchanged (defaults keep outputs identical), including the saved-run hash test.
- [ ] `GET /macro/DGS3MO/asof?date=<first obs date>` returns 404; a later date returns the previous observation, never the same day in strict mode.
- [ ] A backtest request with `source=tiingo, price_basis=split_dividend` runs and returns different hashes from the default request.
- [ ] Missing key returns 400 naming the variable, not a value.
- [ ] Contract test passes; renaming a field is detected (negative test).
- [ ] Standing invariant: replay boundary (`end` earlier than data end never returns later dates; fuzz 50 dates on the new options).

## Out of scope
- Authentication, background jobs.

## Notes for the implementer
Start `uv run market-data serve` (loopback only) and call each new endpoint once; record that you did.
