# Task 09_05: Web: indicators on the episode chart with plain explanations

**Sprint:** 09     **Depends on:** 09_04     **Size:** M
**Concepts to read first:** [09_01](../concepts/09_01_causal-technical-indicators-sma-ema-rsi-and-why-they-describe-not-predict.md), [09_05](../concepts/09_05_accessible-tabs-toggles-and-secondary-chart-panels.md)

## Goal
On the episode screen a learner can switch on a 20-day average, an EMA and an RSI panel, each with a sentence that says what it describes and that it is not a forecast, and a text version of the numbers.

## Context
Blueprint MVP item 5. The chart is a canvas, so accessibility needs a text alternative and labelled toggles.

## What to do
1. Client functions and types for the indicators route.
2. Toggle buttons (`aria-pressed`) "20-day average", "EMA", "RSI" under the chart; lines drawn with theme colours from `chartTheme.ts`; the RSI panel below with the 30 and 70 lines.
3. A one-sentence explanation per indicator in `src/copy/` (reading ease 60 or more, no banned words, no "signal", "buy" or "sell").
4. A "Show the numbers" disclosure with a small table of the last 10 values per active indicator.
5. Tests: toggles named and pressed state exposed; a request is made once per toggle; no data beyond the revealed day is drawn; keyboard use; copy tests.

## Where to do it
`apps/web/src/episode/`, `src/copy/`, `test/indicators.test.tsx`.

## Inputs
Gateway route from 09_04.

## Deliverables
Toggles, panel, copy, tests.

## Acceptance criteria / tests
- [ ] Every control has a visible label and works from the keyboard.
- [ ] The explanation text passes copy and banned-word tests; the words buy, sell and signal never appear.
- [ ] The text table equals the plotted values (reconciliation test).
- [ ] Advancing the episode extends the lines by exactly the new days.

## Out of scope
More indicators, drawing tools.

## Notes for the implementer
An indicator is a description. Say so on the screen.
