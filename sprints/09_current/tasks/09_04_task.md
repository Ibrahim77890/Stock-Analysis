# Task 09_04: Gateway: indicator and journal routes with ownership and limits

**Sprint:** 09     **Depends on:** 09_02, 09_03     **Size:** M
**Concepts to read first:** [09_06](../concepts/09_06_append-only-records-and-reconciling-a-ledger.md), [09_02](../concepts/09_02_paper-trading-without-future-leakage-recording-a-decision-before-the-outcome.md)

## Goal
A signed-in learner can ask for indicators and record or read decisions on their own episodes through the gateway only.

## Context
Sprint 06 and 07 patterns: 404 for others' objects, whitelisting, plain errors, durable limits (Sprint 08).

## What to do
1. Routes: `GET /episodes/:id/indicators`, `POST /episodes/:id/decisions` (body: `day`, `stance`, `reason`, `client_key`, `cost_bps`), `GET /episodes/:id/decisions`; ownership via `app.learner_episode`; the same 404 for unknown, foreign and malformed ids.
2. Whitelist every reply; DTOs; Swagger summaries; 30 decisions a minute per learner through the durable limiter (kind `decision`).
3. Plain error messages mapped from Python.
4. Regenerate `openapi-gateway.json` and the web types.
5. Tests: ownership isolation fuzz (100 attempts), whitelist drops unexpected upstream fields, limiter 429 with `Retry-After`, idempotent double submit, contract test with a renamed-field negative.

## Where to do it
`apps/api/src/journal/`, `dto.ts`, `python-client.ts`, `test/journal.spec.ts`.

## Inputs
Python routes from 09_02 and 09_03.

## Deliverables
Module, DTOs, tests, contracts.

## Acceptance criteria / tests
- [ ] Foreign or unknown episode ids give identical 404 bodies and cause zero Python calls.
- [ ] A leaking fake Python adds `symbol`, `start_date` and `kind`; none reaches the reply.
- [ ] 31st decision in a minute is 429 with `Retry-After`; refused calls are not stored.
- [ ] Contract tests pass and detect a renamed field; `check:python-api` passes.

## Out of scope
Screens.

## Notes for the implementer
A decision log belongs to the learner; never list another learner's.
