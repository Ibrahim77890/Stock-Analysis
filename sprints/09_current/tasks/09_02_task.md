# Task 09_02: Causal indicators in Python: SMA, EMA, RSI and returns, with Swagger

**Sprint:** 09     **Depends on:** none     **Size:** M
**Concepts to read first:** [09_01](../concepts/09_01_causal-technical-indicators-sma-ema-rsi-and-why-they-describe-not-predict.md)

## Goal
The Python service can compute SMA, EMA and RSI for any list of closes, causally, and expose them for an episode using only the bars the learner can already see.

## Context
Blueprint MVP item 5 (inspect a basic technical indicator). The Sprint 03 engine already has a causal moving average; this task adds a small, tested, documented indicator module and an episode endpoint that respects the replay boundary.

## What to do
1. `services/market-data/src/market_data/indicators/` (new package): `sma`, `ema`, `rsi` (Wilder smoothing, 14 days by default), each returning `None` for the warm-up days; docstrings state the formula.
2. Hand-computed examples in tests (a 5-day SMA on 10 closes, an EMA with a known first value, an RSI on a classic worked example) and property tests: output length equals input length; warm-up length is N-1 (SMA) or N (RSI).
3. **Causality test:** for random series, values on the first k bars equal the first k values on all bars (truncation test), for all three indicators.
4. Router `Indicators` with `GET /episodes/{id}/indicators?name=sma&window=20` returning values for the visible days only (day numbers, never dates or symbols), caps: window 2 to 200, names `sma|ema|rsi`; 404 for an unknown episode; 422 for bad input. Token check like the Learning router.
5. Every function listed in Swagger (tags, summaries); refresh `docs/02-domain/openapi-market-data.json`.

## Where to do it
`services/market-data/src/market_data/indicators/`, `api/routers/indicators.py`, `tests/indicators/`.

## Inputs
Episode bars from the Learning module (visible days only).

## Deliverables
Indicator package, router, tests, refreshed OpenAPI.

## Acceptance criteria / tests
- [ ] Hand-computed examples match to 1e-9.
- [ ] The truncation test passes for SMA, EMA and RSI; a deliberately centred window fails it (negative).
- [ ] The endpoint never returns more days than the episode has revealed; after `advance` it returns more; the reply has no date or symbol (leak scan).
- [ ] Bad names or windows give 422 with a plain message; unknown episodes 404.
- [ ] Standing invariants: causality, replay boundary, reproducibility (same inputs, same outputs).

## Out of scope
Other indicators (MACD, Bollinger), screens, the gateway route.

## Notes for the implementer
State the RSI variant in the docstring and the docs; do not silently choose.
