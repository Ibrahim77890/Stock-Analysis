# Task 01_05: Explore and profile the raw data

**Sprint:** 01     **Depends on:** 01_04     **Size:** M
**Concepts to read first:** [01_01 OHLCV](../concepts/01_01_ohlcv-and-candles.md), [01_03 Corporate actions](../concepts/01_03_corporate-actions-and-adjusted-prices.md), [01_06 Data quality](../concepts/01_06_data-quality-validation.md)

## Goal
A written profile of what the raw data actually looks like, before any schema is final.

## Context
Blueprint Week 2: "Inspect missing dates, duplicate records, and invalid values." Findings feed the schema (01_06) and rules (01_08).

## What to do
1. Create a profiling script (Python + Polars; a notebook is optional) that loads all raw bar files.
2. Per symbol, report: row count, first and last date, number of duplicate dates, rows where `high < max(open, close)` or `low > min(open, close)`, rows with `volume = 0`, rows with a null in any column, and the largest absolute daily return.
3. List the 10 largest absolute daily moves across the universe and, for each, say whether a corporate-action record explains it.
4. For AAPL around 2020-08-31 and NVDA around 2024-06-10, print the raw close before/after the split and the split-adjusted close you compute by hand. Show the return with and without adjustment.
5. Count how many weekday dates are missing per symbol (do not classify yet; that is 01_08).
6. Write `data-profile-v1.md` in the domain docs folder with the findings, a table, and a list of "surprises".
7. Add a section "Decisions this implies for the schema" (e.g. column types, nullable columns).

## Where to do it
- Folder / file: profiling script in the Python code folder (e.g. `scripts/profile_raw.py`); report in the domain docs folder.
- Technology: Python, Polars.

## Inputs
Raw Parquet from 01_04; corporate-action files.

## Deliverables
- Profiling script, `data-profile-v1.md`.

## Acceptance criteria / tests
- [ ] Script is deterministic: two runs produce byte-identical report tables (sort everything).
- [ ] Report contains the numbers requested in step 2 for every symbol in the universe.
- [ ] Split demonstration shows an unadjusted return near -75% (AAPL) or -90% (NVDA) and an adjusted return within +-15%.
- [ ] At least one finding is something you did not expect (write it down; "none" is acceptable only with evidence).

## Benchmark
Record script runtime and peak memory in the report (informational).

## Out of scope
Fixing data. Observe and document only.
