# Task 01_10: Document decisions and close the sprint

**Sprint:** 01     **Depends on:** 01_01 to 01_09     **Size:** S
**Concepts to read first:** [01_04 Provenance](../concepts/01_04_data-provenance-and-licensing.md)

## Goal
Everything decided in this sprint is written down so the next sprint (and the sprint agent) can rely on it.

## Context
The sprint agent builds `current_status.md` from what exists in the repository and in `completed/`.

## What to do
1. Write short Architecture Decision Records (one file each; format: Context, Decision, Alternatives, Consequences) in the docs folder for at least: (a) raw prices + separate corporate actions rather than adjusted prices, (b) PostgreSQL only with schemas by owner, (c) data source choice and license position, (d) quarantine-not-delete policy.
2. Update the glossary and data dictionary to match what was built (types, columns, any new terms).
3. Write `README` section "How to reproduce Sprint 1": the ordered list of commands from an empty machine to a loaded database, a quality report, and the benchmark.
4. For each task, add a short note file to `sprints/01_current/completed/` named `<task id>.md` (what was done, where, evidence, deviations). Put anything unfinished in `sprints/01_current/pending/` the same way.
5. Run the full test suite and record the result.
6. Tell the sprint agent to close the sprint.

## Where to do it
- Folder / file: docs folder (ADRs, README), `sprints/01_current/completed/` and `pending/`.
- Technology: Markdown.

## Inputs
All previous task outputs.

## Deliverables
- At least 4 ADRs, updated dictionary and glossary, reproduction guide, completion notes.

## Acceptance criteria / tests
- [ ] Following the reproduction guide on a fresh clone and an empty database ends with a passing test suite and a quality report (try it, or have someone else try).
- [ ] Every task has a note in `completed/` or `pending/`.
- [ ] `pytest` passes; the number of tests and result are recorded.

## Benchmark
Not applicable.

## Out of scope
New features.
