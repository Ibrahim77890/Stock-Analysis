# Task 01_03: Choose the symbol universe and record data-source terms

**Sprint:** 01     **Depends on:** 01_02     **Size:** S
**Concepts to read first:** [01_04 Provenance and licensing](../concepts/01_04_data-provenance-and-licensing.md)

## Goal
A fixed, versioned universe of about 50 US symbols, and a table stating what each candidate data source allows.

## Context
Blueprint 25.6 plan. A small, deliberate universe makes every later test understandable. Include symbols that exercise corporate actions.

## What to do
1. Create `universe_v1.csv` with columns `symbol, name, type (stock|etf), sector, reason_included`.
2. Choose about 50 symbols: ~12 broad/sector ETFs (e.g. SPY, QQQ, IWM, DIA, XLK, XLF, XLE, XLV, TLT, GLD); ~35 large liquid stocks across sectors; and these **split test cases**: AAPL (4-for-1, Aug 2020), TSLA (5-for-1 Aug 2020; 3-for-1 Aug 2022), NVDA (4-for-1 Jul 2021; 10-for-1 Jun 2024), AMZN (20-for-1 Jun 2022), GOOGL (20-for-1 Jul 2022), WMT (3-for-1 Feb 2024). Verify every split date against a source before relying on it and put the source in `reason_included`.
3. Fix the date range: `2016-01-04` to `2025-12-31` (change only if the provider's free plan limits history; record why).
4. In the Sources section of the data dictionary (01_02), add a row for each of: Alpaca (free plan), Stooq bulk, Kaggle "Huge Stock Market Dataset", SEC EDGAR, yfinance. Columns: URL, what we use it for, adjustment status, feed, license/terms summary (read the actual terms page and quote the relevant sentence), redistribution allowed? (yes/no/unclear), rate limits, retrieval date of terms.
5. Choose the **primary source** for daily bars (default: Alpaca free plan with `adjustment=raw`) and the fallback (Kaggle dataset, no account needed). Write one paragraph justifying the choice.
6. Create an Alpaca account and API keys if using Alpaca; store keys only in `.env`.

## Where to do it
- Folder / file: universe file in the data-definitions location you chose (committed, small); sources table in the data dictionary.
- Technology: CSV, Markdown.

## Inputs
Blueprint sections 6.3, 6.4, 25.

## Deliverables
- `universe_v1.csv` (committed), filled Sources section, primary-source decision.

## Acceptance criteria / tests
- [ ] CSV loads with Polars; 45-60 rows; no duplicate symbols (write a 5-line pytest for this).
- [ ] Every row has a non-empty `reason_included`.
- [ ] Every source row has a quoted license sentence or the explicit text "terms unclear".

## Benchmark
Not applicable.

## Out of scope
Delisted symbols (survivorship demo is a later sprint; note it as a known gap).

## Notes for the implementer
A current-day universe is itself survivorship-biased. Record that in the status log as a known limitation.
