# Task 08_05: Web learning path and lesson page with questions

**Sprint:** 08     **Depends on:** 08_03     **Size:** L
**Concepts to read first:** [08_01](../concepts/08_01_learning-design-for-beginners-worked-examples-retrieval-practice-and-feedback.md), [08_03](../concepts/08_03_checking-answers-on-the-server-and-idempotent-progress.md), [08_05](../concepts/08_05_explorable-explanations-small-demos-that-teach-one-idea.md), [08_06](../concepts/08_06_testing-accessibility-keyboard-accessibility-tree-and-screen-readers.md)

## Goal
A beginner sees a path of six lessons with their own progress, reads a lesson one step at a time, answers three questions with explained feedback, and is pointed to the Learn or Lab screen that practises the idea.

## Context
The interface was redesigned in Sprint 07 (tokens, cards, icons, calm layout). This task adds the first guided experience on top of it. The lessons come from the gateway (08_03); the web app holds no answer key.

## What to do
1. Regenerate `apps/web/src/api/schema.d.ts`; add client functions for the four lesson routes.
2. Add routes `/path` (the learning path) and `/path/:slug` (a lesson) and a "Path" link first in the navigation. Make "Path" the page a signed-in learner lands on after sign-in (Home still explains the product).
3. **Path page:** six lesson cards in order with title, summary, minutes, a progress bar ("2 of 5 steps, 1 of 3 questions") and a state chip (Not started, In progress, Done); the next lesson is marked "Start here". A short sentence says progress is private and is a record, not a grade.
4. **Lesson page:** one step at a time with "Back" and "Next", a progress bar, the `more` text behind "Show more", glossary markers working, and a "Mark as read" call when a step is reached (idempotent). After the last step show the three questions one at a time: choose an option, press "Check my answer", see "Right" or "Not yet" with the explanation of the chosen option, a way to try again after a wrong answer, and (when the server allows) the correct option. No score, no ranking.
5. **Practice link:** each lesson ends with a button to the screen that practises it (Learn for lessons 1 to 4, Lab for 5 and 6).
6. Copy for the new screens in `src/copy/lessons.ts` (reading ease 60 or more, sentences up to 25 words, no banned words); lesson text itself comes from the server and is checked in 08_02.
7. Component tests with fixtures: the path renders progress and "Start here"; a lesson steps forward and back and marks each step once; the question flow shows right and wrong feedback from fixtures; the correct option is never shown before the server sends it; errors (404, 429, network) show plain messages and keep the page usable.

## Where to do it
- Folder / file: `apps/web/src/lessons/`, `apps/web/src/copy/lessons.ts`, `apps/web/src/api/`, `apps/web/src/App.tsx`, `apps/web/src/components/Layout.tsx`, `apps/web/test/lessons.test.tsx`.
- Technology: React, TypeScript, Vitest + Testing Library.
- Database schema/ownership: none in the browser.

## Inputs
- Gateway lesson routes (mocked in component tests, real in 08_07), the Sprint 07 design system.

## Deliverables
- Path and lesson pages, question flow, copy, tests.

## Acceptance criteria / tests
- [ ] Every control has a visible label and works from the keyboard (component test tabs through a lesson; the walk checks it in a browser in 08_07).
- [ ] A double click on "Check my answer" sends one request.
- [ ] No text on the lesson page says "score", "rank", "points" or "level" (negative scan; the product teaches doubt, not competition).
- [ ] Copy tests, contrast tests and all earlier web tests pass; no hard-coded colours in `src/lessons`.
- [ ] A 404 for an unknown lesson shows a plain message and a link back to the path.
- [ ] Standing invariants: idempotency (steps marked once), reconciliation (the progress bar equals the numbers from the gateway).

## Out of scope
- The interactive demos (08_06), certificates, streaks and badges, a lesson editor.

## Notes for the implementer
The wrong-answer text must never shame. "Not yet" plus the reason is the whole message.
