# Task 07_06: Lab results in the web app: honest cards, growth chart, costs, luck, ideas tried

**Sprint:** 07     **Depends on:** 07_05     **Size:** L
**Concepts to read first:** [07_01](../concepts/07_01_what-a-backtest-shows-and-what-it-does-not.md), [07_02](../concepts/07_02_trying-many-ideas-overfitting-and-the-number-of-tries.md), [07_04](../concepts/07_04_luck-controls-for-a-strategy.md), [07_06](../concepts/07_06_explaining-performance-numbers-and-charts-to-beginners.md)

## Goal
After a run, the learner sees what happened in plain words with the benchmark beside every number, how it changes with costs, how often luck alone does as well, how many ideas they have tried, and a fixed "what this does not tell you" list.

## Context
Blueprint 23.2 (educational honesty: show the benchmark, costs, luck and number of tries; never present a result as proof). The Python run result (07_02) and the gateway whitelist (07_04) define the data; this task only presents it.

## What to do
1. **Result cards** on the study page, in a fixed order:
   1. Headline sentence built from data: "In these N practice years, 100 in the rule became X; 100 in buy and hold became Y." No verdict words.
   2. Growth chart: both lines start at 100, **log scale**, labelled lines (direct labels at the right end plus a legend), different dash styles, axis title "Growth of 100 (log scale)", built with Lightweight Charts as in Sprint 06; a text table of yearly values below it as the accessible alternative (toggle "Show as table").
   3. Numbers card: total return, per year, worst fall, time in the stock, trades; rule and buy and hold side by side, each with a one-line meaning (copy). Sharpe behind "Show more".
   4. Costs card: the cost table (0 to 20 bps) as a small table with the learner's chosen cost highlighted and a sentence that says where the result changes sign relative to buy and hold, if it does (computed in the page from the table, no new statistics).
   5. Luck card: "Mixing up the order of the days 100 times, X of 100 mixed runs did as well or better" with the median and a range, and the warning that this tests timing luck only.
   6. Ideas tried card: the count, a list of the tries (rule, result), and the overfitting meter when two or more exist, with a sentence of the form "The more rules you try, the better the best one looks by luck alone."
   7. **What this does not tell you** (fixed list, always visible): one stock and one period; practice years only; costs and tax simplified; the future may differ; trying many rules inflates the best result; not advice.
2. **Warnings** returned by Python (fewer than 20 trades, short window) appear above the cards in a plain notice with an icon and text (not colour alone).
3. **Run history:** each run adds a row to the "ideas tried" list; repeated identical runs show "already counted" and do not add a row. Clicking a row reloads that run's cards from a new gateway call (the same numbers).
4. Loading and error states: a run shows a progress message ("Running... this takes a few seconds"), disables the button, and a 429/504/422 error shows a plain message with what to do next ("wait a moment", "try shorter averages").
5. Copy in `src/copy/lab.ts` (extended) with the same reading-ease checks. All numbers formatted by one helper (percent with a sign, one decimal; no more than 3 significant figures for ratios).
6. Tests with fixed fixture results: each card renders its numbers; the headline sentence matches the fixture; the cost sentence is correct for fixtures where the sign flips and where it does not; the notice appears for 12 trades; repeated run shows "already counted"; the chart receives log mode and 300 points or fewer.

- Technology: React, Lightweight Charts, Vitest.
- Database schema/ownership: none.

## Inputs
- Gateway response types (07_04) and fixtures built from a real Python run (saved as JSON under `apps/web/test/fixtures/`, small).

## Deliverables
- Result components, copy, formatting helper, fixtures, tests.

## Acceptance criteria / tests
- [ ] Every number shown has its benchmark beside it (a test fails if a rule number appears without a buy-and-hold counterpart).
- [ ] The "does not tell you" list is present in every state that shows results (test over three fixtures, including one with warnings).
- [ ] No banned word appears in any rendered result text (test renders all fixtures and scans: "beats the market", "edge", "profit", "alpha", "guarantee", "winning", "proof").
- [ ] The chart is created in log mode with both series starting at 100, labelled; a text table with the same values exists and is keyboard-reachable.
- [ ] The cost sentence is correct on both fixtures; a fixture with a missing cost table shows a plain "not available" and does not crash (negative test).
- [ ] Error states for 422, 429 and 504 are shown as plain text and the form is usable again afterwards.
- [ ] Copy reading-ease and sentence-length tests pass; contrast tests pass; no hard-coded colours.
- [ ] Number formatting helper unit tests (signs, rounding, zero, large values).
- [ ] Standing invariants: reconciliation (the numbers on screen equal the fixture values), idempotency (repeat shows "already counted"), replay boundary (the page never shows a date after the practice window; the yearly table labels come from the gateway).

## Out of scope
- Vault flow (07_07), choosing among rules for the learner, rankings, sharing results.

## Notes for the implementer
Write each card's meaning sentence as if explaining to a friend who has never invested. If the sentence needs the word "statistically", rewrite it.
