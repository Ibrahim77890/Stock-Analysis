# Task 07_03: Lab endpoints in Python (Swagger "Lab"), internal token, limits and errors

**Sprint:** 07     **Depends on:** 07_02     **Size:** M
**Concepts to read first:** [07_05](../concepts/07_05_protecting-expensive-endpoints.md), [07_03](../concepts/07_03_the-vault-out-of-sample-holdout-and-one-use-tests.md)

## Goal
Every lab function can be tried by hand in Swagger, with the same internal-token rule as the learning endpoints and clear, safe errors for every cap.

## Context
Continues ADR 0007 (every function in Swagger) and ADR 0014 (internal endpoints behind `X-Internal-Token`). Sprint 06 put the learning endpoints in `api/routers/learning.py`; this task adds a sibling router.

## What to do
1. Add `src/market_data/api/routers/lab.py` (tag **Lab**, token dependency reused from the learning router, included from `api/app.py`) with:
   - `GET /lab/stocks` -> `eligible_symbols`.
   - `POST /lab/studies` (`symbol`, optional `vault_bars`, optional `name`) -> `create_lab_study`.
   - `GET /lab/studies/{study_id}` -> `study_overview`.
   - `POST /lab/studies/{study_id}/runs` (`fast`, `slow`, `cost_bps`, `seed`) -> `run_practice`.
   - `POST /lab/studies/{study_id}/vault` (`fast`, `slow`, `cost_bps`) -> `open_vault`.
2. Error mapping: unknown study 404; `LabLimitError` 422 with a plain message naming the limit and its value; `HoldoutAlreadyUsedError` 409 ("the vault of this study was already opened"); unknown symbol 404; too few sessions 422. No error text contains a vault date, a file path or a stack trace.
3. Pydantic models carry the limits (`ge`, `le`) so Swagger shows them; the authoritative checks stay in `lab/study.py`.
4. Update the Swagger tag descriptions (which endpoints write: study creation, runs and vault), the README Swagger table (Lab row) and refresh `docs/02-domain/openapi-market-data.json`; regenerate `apps/api/src/python/schema.d.ts` and run `npm run check:python-api`.
5. Call each endpoint once on the running service (loopback) and record that you did.

## Where to do it
- Folder / file: `services/market-data/src/market_data/api/routers/lab.py`, `api/app.py`, `tests/lab/test_api_lab.py`, README.
- Technology: FastAPI, Pydantic.
- Database schema/ownership: through `lab/study.py` only.

## Inputs
- 07_02 functions; the learning router for the token dependency.

## Deliverables
- Router, refreshed OpenAPI, tests, README row.

## Acceptance criteria / tests
- [ ] A test lists every Sprint 07 Python function with its endpoint (inventory test, as in Sprint 06).
- [ ] With `INTERNAL_API_TOKEN` set every Lab call without the header returns 401 and with it works; with it unset the endpoints work (and the OpenAPI text says so); the token never appears in a response or log line.
- [ ] End to end through the API on a crafted database: create a study, run three rules (the third a repeat of the first: `counted = false`), read the overview (trial count 2), open the vault once (200) and again (409), and the overview then shows the vault as opened.
- [ ] Each cap returns 422 with a message that states the limit (parametrised test over the six caps), and the database is unchanged afterwards.
- [ ] **Vault privacy over HTTP (negative test):** every response of every Lab endpoint before the vault is opened, including error bodies and headers, contains no date after the practice end (scan for ISO dates and years inside the vault years).
- [ ] The response of `POST .../runs` validates against its Pydantic response model; equity curves have at most 300 points.
- [ ] Contract test passes; renaming a field is detected (existing negative test).
- [ ] Live pass recorded: each endpoint called once against the running service.
- [ ] Standing invariants: replay boundary (no vault dates), idempotency (repeat run), reproducibility (same body twice gives the same numbers).

## Out of scope
- Users and ownership (the gateway, 07_04), the web pages, background jobs.

## Notes for the implementer
Do not echo the study's `practice_end` or any vault date in any field before the vault is opened: the lab shows years of history as counts ("17 years of practice data"), not dates.
